## 🏗️ Framework Overview

**Page Object Model (POM)** based test automation framework featuring:
- Dynamic test parameterization with `@pytest.mark.parametrize`
- Cross-browser support (Chrome/Firefox/Edge)
- Error handling and screenshot capture
